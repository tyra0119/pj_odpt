# 交通データ白地図 — カバレッジデータ

日本の公共交通オープンデータが**どこにあるか**を、全国の母集団に対して集計したもの。
実測日 **2026-09-09**。

## データの所在（この4分類が全ファイル共通の軸）

地図の画面表記と、CSV に入っている値は綴りが違う。中身は同じもの。

| 地図の表記 | CSVの値 | 意味 |
|---|---|---|
| ODPT | `通年オープン` | ODPT にあり、通年で使える |
| ODPT（期間限定） | `期間限定` | ODPT にあるが 2027-03-13 で終了する |
| ODPT外 | `ODPT外にあり` | ODPT には無いが gtfs-data.jp 等にはある |
| なし | `データなし` | 確認できた範囲では、どこにも機械可読なデータが無い |

ODPT を先に見て、ODPT に無いものだけを `ODPT外にあり` としている。

## 主な結果

|  | ODPT | ODPT（期間限定） | ODPT外 | なし | 母集団 |
|---|---:|---:|---:|---:|---:|
| 鉄道（路線） | 85 | 107 | 24 | 381 | 597 |
| バス（停留所） | 29,173 | 2,286 | 57,589 | 189,467 | 278,515 |

## ファイル

### `railway_coverage.csv`

鉄道路線ごとのデータの所在。597行。

| 列 | 意味 |
|---|---|
| `n02_operator` | 国土数値情報 N02 の運営会社名 |
| `n02_line` | 同 路線名 |
| `op_kind` | 事業者種別（JR新幹線／JR在来線／公営鉄道／民営鉄道／第三セクター） |
| `kind` | 鉄道区分（普通鉄道／軌道／モノレール など） |
| `stations` | N02 上の駅数 |
| `segments` | N02 上の線分数 |
| `status` | データの所在。値は 通年オープン／期間限定／ODPT外にあり／データなし（地図では ODPT／ODPT（期間限定）／ODPT外／なし と表記） |
| `status_after` | 2027-03-13 以降の所在（期間限定が消えたあと） |
| `odpt_railways` | 対応する odpt.Railway の ID（複数は | 区切り） |
| `odpt_operator` | 対応する odpt.Operator の ID |
| `gtfs_org` | gtfs-data.jp の事業者ID（ODPT外にある場合） |
| `gtfs_name` | 同 事業者名 |

## ライセンス

この集計結果は **CC BY 4.0**。出典として「交通データ白地図」と上記の各データを示すこと。

**元データそのものは再配布していない。** ここにあるのは、母集団に対して所在を判定した結果（分類と件数）である。元データを使うときは、各提供元の条件に従うこと。特に ODPT のチャレンジ限定ライセンスのデータは、コンテスト期間外は利用できない。

## 読むときの注意

- `データなし` は「**確認できた範囲では**無い」という意味。事業者が自社サイトで独自に公開している可能性は残る。
- バスの母集団 P11 は2022年、オープンデータ側は2026年。4年のずれがあり、廃止された停留所が `データなし` に混じる。鉄道（N02-24）より条件が悪い。
- バスの判定半径は100m。25m〜200mで 22.8%〜32.8% と動くので、一点ではなく帯で読むこと。
- 人口は2015年のみ国勢調査の実測、2020年以降は推計。
- シェアサイクル・フェリー・デマンド交通は全国の母集団が機械可読な形で存在しないため、割合を出していない。
